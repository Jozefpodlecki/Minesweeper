# Minesweeper

![rustc](https://img.shields.io/badge/rustc-1.94.0-blue.svg)
![CI](https://github.com/Jozefpodlecki/lm-studio-api-rs/actions/workflows/ci.yml/badge.svg)
![wasm-bindgen](https://img.shields.io/badge/wasm--bindgen-0.2.114-blue.svg)

A classic single-player puzzle game centered on logic, probability, and risk management.

The objective is to uncover all non-mined cells on a grid without triggering hidden mines. Each revealed cell provides numeric clues indicating how many adjacent cells contain mines, enabling the player to deduce safe moves and mark dangerous positions.
